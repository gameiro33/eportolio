Correlation and Regression

This exercise was carried out based on prefilled jupyter notebooks. The corresponding code and analysis can be found here.


Lessons Learned:

  • Correlation and Regression.

    • Pearson's correlation coefficient quantifies the strength and direction of linear relationships between variables, with values close to 1 (0.888 in the first example) indicating strong positive correlation and values close to -1 (-0.759 in the second example) indicating strong negative correlation. Linear regression not only reveals the relationship between variables but enables prediction of future values, as demonstrated by calculating that when x=10, the predicted y value is 85.59.

  • Linear Regression.

    • The scipy.stats.linregress function provides a complete statistical analysis of linear relationships, calculating not just correlation but also slope, intercept, and significance values in a single function call. Creating a predictive model is straightforward by applying the derived formula (y = mx + b), allowing us to make predictions for any input value, as demonstrated when predicting that x=10 would yield y=85.59.

  • Multiple Linear Regression

    • Multiple linear regression enables prediction using several input variables simultaneously, as demonstrated by predicting CO2 emissions (107.2g) based on both a car's weight (2300kg) and engine volume (1300cm³).The coefficient values (0.00755095 for weight, 0.00780526 for volume) precisely quantify each variable's independent impact on the outcome, allowing us to calculate that a 1000kg weight increase would result in approximately 7.55g more CO2 emissions.

  • Polynomial Regression:

    • Polynomial regression can model non-linear relationships between variables by fitting higher-degree curves to data points, as demonstrated by using numpy.polyfit with degree 3 to capture the U-shaped pattern in the data. The numpy library provides efficient tools (poly1d and linspace) for both creating polynomial models and generating smoothly plotted curves, enabling effective visualization of complex relationships that simple linear regression cannot accurately represent.
